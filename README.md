# To-Do 리스트

학생들이 공부와 일상 일정을 한곳에서 관리할 수 있는 반응형 To-Do 리스트입니다. 할 일의 날짜와 마감일, 카테고리, 반복 여부를 지정하고 완료 현황을 확인할 수 있습니다.

## 소개

- 할 일을 추가·수정·삭제하고 완료 상태를 체크할 수 있습니다.
- 일정 날짜와 선택적 마감 기한을 설정하고, 매일 또는 선택한 요일에 반복할 수 있습니다.
- 공부, 과제, 시험, 일상, 기타 기본 카테고리를 제공하며 카테고리를 직접 추가·수정·삭제할 수 있습니다.
- 전체·오늘·예정·기한 초과·완료·미완료 및 카테고리별로 일정을 필터링합니다.
- 전체와 카테고리별 완료 수 및 진행률을 표시합니다.
- 완료를 체크하면 꽃잎 애니메이션이 나타나고, 삭제 전에는 확인 팝업을 표시합니다.
- 데이터는 현재 브라우저의 `localStorage`에 저장됩니다. 계정이나 서버가 필요하지 않으며 다른 브라우저·기기와 동기화되지 않습니다.

## 어떻게 만들었나요

먼저 PRD의 기능 요구사항과 완료 기준을 기준으로 구현 범위를 정리하고, 각 기준이 화면과 동작에서 확인될 수 있도록 계획했습니다. HTML5와 Vanilla JavaScript로 화면과 To-Do 동작을 구성하고, Tailwind CSS CDN을 반응형 레이아웃에 사용했습니다. 추가 디자인은 `style.css`에 작성했으며 일정·카테고리·반복 일정 완료 기록은 브라우저의 `localStorage`에 저장합니다.

구현 과정에서 입력 검증, HTML 태그가 실행되지 않는 안전한 텍스트 표시, 저장 데이터 예외 처리, 빈 상태, 모바일 레이아웃을 함께 고려했습니다. 반복 일정의 완료 여부는 날짜별로 따로 저장하며, 진행률은 할 일 정의별로 계산합니다. 반복 할 일은 오늘 발생하는 일정이 오늘 완료된 경우에 완료로 계산합니다.

## Bootstrap vs Tailwind

Bootstrap은 버튼·입력창·그리드 같은 미리 준비된 컴포넌트 클래스를 조합하는 방식이고, Tailwind는 `grid`, `gap-4`, `md:grid-cols-2`처럼 작은 유틸리티 클래스를 HTML에 조합해 화면을 구성하는 방식입니다. 그래서 Bootstrap은 기본 컴포넌트를 빠르게 적용하기 좋고, Tailwind는 반응형 배치와 간격을 요소별로 세밀하게 조정하기 편합니다.

이번 버전은 Tailwind CSS를 CDN으로 불러오도록 선택했습니다. 화면의 그리드와 반응형 배치를 HTML에서 바로 조정하고, 카드와 할 일 목록 등 앱 고유 스타일은 `style.css`로 분리했습니다. 별도의 설치나 빌드 과정 없이 실행할 수 있는 점도 실습에 적합합니다.

| 항목 | Bootstrap 방식 | Tailwind 방식 |
| --- | --- | --- |
| 스타일 적용 | `row`, `col-*`, `btn` 등 컴포넌트·그리드 클래스 사용 | `grid`, `gap-*`, `md:*` 등 유틸리티 클래스 조합 |
| 세부 조정 | 컴포넌트 기본 스타일을 사용하고 필요 시 CSS로 보완 | 요소별 유틸리티를 조합해 간격과 반응형 배치를 지정 |
| 이 프로젝트의 선택 | 비교 대상으로 참고 | 최종 화면에 사용 |

> Tailwind CDN은 개발·학습용입니다. 실제 서비스에서는 빌드 과정을 통해 필요한 CSS만 생성하는 방식을 권장합니다. CDN 스타일을 가져오므로 페이지를 처음 열 때 인터넷 연결이 필요합니다.

## 실행 방법

저장소 루트에서 로컬 웹 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다. 서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

### GitHub Pages 배포

GitHub Pages를 `gh-pages` 브랜치의 루트(`/`)로 설정하면 저장소 소유자에 따라 다음 주소 형식으로 접속할 수 있습니다.

<https://leey102.github.io/26-w08-todo/>

Pages 설정과 배포가 완료된 뒤 주소를 확인하세요. 현재 README 작성 시점에는 Pages 배포 여부를 확인하지 못했습니다.

## 커스터마이징한 부분

- 기본 요구사항 외에 완료 체크 시 꽃잎이 퍼지는 효과를 추가했습니다. 사용자가 모션 감소를 설정한 경우에는 애니메이션을 생략합니다.
- 브라우저 기본 확인창 대신, 삭제 대상과 반복 일정 전체 삭제 안내를 표시하는 모달을 만들었습니다. 금빛 모자이크 분위기의 장식 아이콘은 앱을 위해 별도로 구성했습니다.
- 주간 반복 일정에 대해 반복 요일을 하나 이상 선택할 수 있도록 했습니다.
- 기존 Bootstrap 저장 키를 사용하던 데이터가 있으면 새 저장 키로 이전해 기존 데이터를 이어서 사용할 수 있도록 했습니다.
- 입력한 제목은 텍스트로 표시해 HTML이 실행되지 않도록 했으며, 마감일 검증과 저장 실패·손상 데이터 안내를 추가했습니다.

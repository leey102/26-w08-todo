# To-Do 리스트

공부와 일상 일정을 관리하는 반응형 To-Do 리스트입니다. 할 일과 카테고리 관리, 날짜별 반복 일정, 조건별 필터, 진행률, 브라우저 저장 기능을 제공합니다.

## 기술 스택

- HTML5, Vanilla JavaScript
- Tailwind CSS CDN과 앱 전용 `style.css`
- 브라우저 `localStorage`

Tailwind CSS는 CDN으로 불러오므로 실행할 때 인터넷 연결이 필요합니다. CDN 방식은 학습과 프로토타이핑에 적합하며, 실제 서비스에서는 빌드 방식 사용을 권장합니다.

## 실행 방법

저장소 루트에서 간단한 웹 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 데이터는 현재 브라우저의 이 사이트 저장 공간에 보관되며 다른 기기와 동기화되지 않습니다.

## 주요 기능

- 할 일 추가, 수정, 삭제 및 완료 상태 관리
- 일정 날짜, 선택적 마감일, 매일/매주 반복 설정
- 기본 카테고리와 사용자 카테고리 관리 및 카테고리 필터
- 오늘/예정/기한 초과/완료/미완료 일정 필터와 날짜순 정렬
- 전체 및 카테고리별 진행률, 빈 상태 안내, 모바일 반응형 레이아웃
- 완료 체크 시 꽃잎 애니메이션과 삭제 전 확인 모달
- 입력값 안전 처리와 `localStorage` 데이터 유지

## 파일 구성

- [`index.html`](./index.html): 화면 구조와 Tailwind CDN
- [`style.css`](./style.css): 앱 전용 디자인과 반응형 세부 스타일
- [`script.js`](./script.js): 일정·카테고리 동작, 필터, 진행률 및 저장
- [`guide.md`](./guide.md): 실습 및 브랜치 작업 안내
